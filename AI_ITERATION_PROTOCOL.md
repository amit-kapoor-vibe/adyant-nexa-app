# 🛡️ AI Iteration & Preservation Protocol (Adyant Nexa)

**Status:** ACTIVE
**Goal:** To eliminate the "AI Deletion" frustration and preserve successful design iterations.

## 1. The Anchor Rule (Approval is Permanent)
- If the USER praises or approves a design/component, it is considered an **Anchor**.
- AI will **NEVER** overwrite or delete an Anchor unless the USER explicitly says "Replace this" or "Delete this".
- Praise ("I loved it", "This is great") automatically triggers Anchor status.

## 2. The Stack Protocol (Append, Don't Overwrite)
- New ideas, excitement-driven changes, or refinements will be added as **New Sections** below the existing work.
- Example: If `Neural Shankh V1` is liked, and we want to try a new look, we build `Neural Shankh V2` below it.
- This creates a vertical "Evolution Gallery" that the USER can scroll through.

## 3. Explicit Deletion ONLY
- Code removal is restricted.
- Even if a new version is better, the old version stays until an explicit "Cleanup" command is given.
- This ensures that a "bad" new iteration doesn't destroy a "good" old one.

## 4. Developer Responsibility
- Maintain clear component naming (e.g., `ShankhClassic`, `ShankhNeural`, `ShankhPearl`).
- Ensure the `package.json` and core logic remain stable while visual iterations grow.
- Use the "Future Buddy" persona to protect the project's history.

### Rule #5: The Architect's Blueprint (Plan-First)
- Before making any code changes (especially multi-file or structural), the AI must submit a formal **Plan** in a Markdown artifact.
- The AI must wait for the User's explicit **"Proceed"** or **"Go Ahead"** before executing.

### Rule #6: The Emotional Firewall (Anti-Excitement)
- The AI must never get carried away in the "Flow" or "Excitement" of a discussion.
- Even if a change feels "obvious" or "correct" during a chat, the AI **MUST NOT** execute until the User gives a final confirmation.
- Momentum is good, but **Discipline is better.** Stop and wait.
- This ensures alignment and prevents wasted compute on misaligned designs.

**Motto:** *Preserve the Win, Plan the Next, Build the Future.*
