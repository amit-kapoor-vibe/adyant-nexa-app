# Adyant Nexa V1 Database Schema Specification

**Date:** August 27, 2026  
**Database System:** PostgreSQL (Supabase)

---

## 1. Overview & Entity Relationship Architecture

The V1 database schema is designed for multi-tenant scalability, enabling one user/profile to manage multiple businesses over time, while keeping assessment data, calculation scores, profit opportunities, and reports strictly isolated and audit-ready.

```
+----------------+          +-------------------+          +---------------------+
|  auth.users    | 1------* |   businesses      | 1------* |    assessments      |
+----------------+          +-------------------+          +---------------------+
                                                                      |
                                           +--------------------------+--------------------------+
                                           |                          |                          |
                                           v                          v                          v
                                +-------------------+      +-------------------+      +-------------------+
                                |   growth_scores   |      |   opportunities   |      |     reports       |
                                +-------------------+      +-------------------+      +-------------------+
                                                                      |
                                                                      v
                                                           +-------------------+
                                                           |      leads        |
                                                           +-------------------+
```

## 2. Table Definitions

### 2.1 `profiles`
Maps to `auth.users` to store platform user profiles.
- `id` (uuid, PK, references `auth.users.id` ON DELETE CASCADE)
- `full_name` (text)
- `phone` (text)
- `role` (text, default `'user'`, check in `'user'`, `'admin'`)
- `created_at` (timestamptz, default `now()`)
- `updated_at` (timestamptz, default `now()`)

### 2.2 `businesses`
Stores target business profiles.
- `id` (uuid, PK, default `gen_random_uuid()`)
- `user_id` (uuid, nullable FK, references `profiles.id`)
- `name` (text, required)
- `industry` (text, required, e.g. `'fashion_retail'`, `'footwear'`, `'general_retail'`)
- `city` (text)
- `store_count` (integer, default 1)
- `channel_type` (text, default `'offline'`, check in `'offline'`, `'online'`, `'hybrid'`)
- `years_in_business` (integer)
- `annual_revenue_range` (text)
- `website` (text)
- `instagram` (text)
- `created_at` (timestamptz, default `now()`)

### 2.3 `assessments`
Tracks diagnostic runs completed by visitors or logged-in users.
- `id` (uuid, PK, default `gen_random_uuid()`)
- `business_id` (uuid, nullable FK, references `businesses.id`)
- `session_id` (text, indexed for anonymous visitor tracking)
- `status` (text, default `'completed'`, check in `'draft'`, `'completed'`, `'archived'`)
- `raw_inputs` (jsonb, stores multi-step wizard answers)
- `engine_version` (text, default `'1.0.0'`)
- `created_at` (timestamptz, default `now()`)

### 2.4 `growth_scores`
Calculated score results generated by the engine.
- `id` (uuid, PK, default `gen_random_uuid()`)
- `assessment_id` (uuid, FK, references `assessments.id` ON DELETE CASCADE)
- `overall_score` (integer, check between 0 and 100)
- `inventory_score` (integer)
- `marketing_score` (integer)
- `retention_score` (integer)
- `margin_score` (integer)
- `total_estimated_leakage` (numeric(14, 2))
- `created_at` (timestamptz, default `now()`)

### 2.5 `opportunities`
Detailed category-wise leakage & opportunity findings.
- `id` (uuid, PK, default `gen_random_uuid()`)
- `assessment_id` (uuid, FK, references `assessments.id` ON DELETE CASCADE)
- `category` (text, e.g. `'inventory'`, `'marketing'`, `'retention'`, `'margins'`)
- `title` (text)
- `issue_summary` (text)
- `estimated_annual_opportunity` (numeric(14, 2))
- `priority` (text, check in `'HIGH'`, `'MEDIUM'`, `'LOW'`)
- `recommended_action` (text)
- `created_at` (timestamptz, default `now()`)

### 2.6 `leads`
Captured leads from completed growth assessments.
- `id` (uuid, PK, default `gen_random_uuid()`)
- `assessment_id` (uuid, nullable FK, references `assessments.id`)
- `name` (text, required)
- `email` (text, required)
- `phone` (text, required)
- `city` (text)
- `business_name` (text)
- `status` (text, default `'NEW'`, check in `'NEW'`, `'CONTACTED'`, `'QUALIFIED'`, `'CLOSED'`)
- `created_at` (timestamptz, default `now()`)

### 2.7 `reports`
Generated Growth Blueprint reports.
- `id` (uuid, PK, default `gen_random_uuid()`)
- `assessment_id` (uuid, FK, references `assessments.id`)
- `report_type` (text, default `'free_summary'`)
- `pdf_url` (text)
- `report_data` (jsonb)
- `created_at` (timestamptz, default `now()`)

## 3. SQL Migration Script (Supabase DDL)

```sql
-- Enable UUID Extension
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 1. Profiles Table
CREATE TABLE IF NOT EXISTS public.profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  full_name TEXT,
  phone TEXT,
  role TEXT DEFAULT 'user' CHECK (role IN ('user', 'admin')),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Businesses Table
CREATE TABLE IF NOT EXISTS public.businesses (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES public.profiles(id) ON DELETE SET NULL,
  name TEXT NOT NULL,
  industry TEXT NOT NULL,
  city TEXT,
  store_count INT DEFAULT 1,
  channel_type TEXT DEFAULT 'offline' CHECK (channel_type IN ('offline', 'online', 'hybrid')),
  years_in_business INT,
  annual_revenue_range TEXT,
  website TEXT,
  instagram TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Assessments Table
CREATE TABLE IF NOT EXISTS public.assessments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  business_id UUID REFERENCES public.businesses(id) ON DELETE SET NULL,
  session_id TEXT,
  status TEXT DEFAULT 'completed' CHECK (status IN ('draft', 'completed', 'archived')),
  raw_inputs JSONB NOT NULL,
  engine_version TEXT DEFAULT '1.0.0',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. Growth Scores Table
CREATE TABLE IF NOT EXISTS public.growth_scores (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  assessment_id UUID NOT NULL REFERENCES public.assessments(id) ON DELETE CASCADE,
  overall_score INT CHECK (overall_score BETWEEN 0 AND 100),
  inventory_score INT,
  marketing_score INT,
  retention_score INT,
  margin_score INT,
  total_estimated_leakage NUMERIC(14, 2) DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 5. Opportunities Table
CREATE TABLE IF NOT EXISTS public.opportunities (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  assessment_id UUID NOT NULL REFERENCES public.assessments(id) ON DELETE CASCADE,
  category TEXT NOT NULL,
  title TEXT NOT NULL,
  issue_summary TEXT NOT NULL,
  estimated_annual_opportunity NUMERIC(14, 2) DEFAULT 0,
  priority TEXT CHECK (priority IN ('HIGH', 'MEDIUM', 'LOW')),
  recommended_action TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 6. Leads Table
CREATE TABLE IF NOT EXISTS public.leads (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  assessment_id UUID REFERENCES public.assessments(id) ON DELETE SET NULL,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT NOT NULL,
  city TEXT,
  business_name TEXT,
  status TEXT DEFAULT 'NEW' CHECK (status IN ('NEW', 'CONTACTED', 'QUALIFIED', 'CLOSED')),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 7. Reports Table
CREATE TABLE IF NOT EXISTS public.reports (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  assessment_id UUID NOT NULL REFERENCES public.assessments(id) ON DELETE CASCADE,
  report_type TEXT DEFAULT 'free_summary',
  pdf_url TEXT,
  report_data JSONB NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Indexes for Query Performance
CREATE INDEX IF NOT EXISTS idx_assessments_session ON public.assessments(session_id);
CREATE INDEX IF NOT EXISTS idx_growth_scores_assessment ON public.growth_scores(assessment_id);
CREATE INDEX IF NOT EXISTS idx_opportunities_assessment ON public.opportunities(assessment_id);
CREATE INDEX IF NOT EXISTS idx_leads_created ON public.leads(created_at DESC);
```
