## 💎 THE "FORBIDDEN" FIX (Golden Rule)
Lark API kabhi bhi kaam nahi karega jab tak aap App ko **Base** ke andar invite nahi karenge.

1. Open Base -> Click **`...` (More)**.
2. Go to **More** -> **Add Document Application**.
3. Search **`Adyant Nexa Connector`** -> Add as **Can Edit**.

## ⚡ QUICK DEBUGGING CHECKLIST
- [ ] **Status 500?** Check if `phone` variable is destructured in code.
- [ ] **Forbidden 403?** Check if app is added to Base applications.
- [ ] **Date Error?** Lark expects `Date.now()` (milliseconds), not strings.
